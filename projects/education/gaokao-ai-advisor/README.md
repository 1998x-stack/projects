# LLM × 高考志愿填报 | Gaokao AI Advisor

## Project overview / 项目概述

本项目研究以 LLM 支持中国高考志愿填报和家庭升学决策的创业机会，比较教育部官方服务、国内垂直平台、互联网大厂的高考 Agent，以及 Product Hunt / Hacker News 上的海外 AI 升学顾问与相关社区反馈。

**Positioning hypothesis / 产品假设：** 不再重复提供通用的“AI 冲稳保”推荐，而是通过可溯源的官方数据、确定性约束检查与有解释的风险审计，帮助考生与家长核实已有志愿草表并协同决策。

## Published deliverable / 已发布文稿

- [**全球竞品、用户声音与创业机会深度调研（2026-11-09）**](reports/research-2026-11.md) — 28 条来源，覆盖产品定位、优缺点、交互设计、真实用户反馈、MVP 范围、架构建议、成功标准和风险边界。

## Key conclusions / 核心结论

1. **免费服务竞争激烈。** 官方、高流量互联网产品已能提供数据检索、选校与 AI 推荐；不能将“能生成报告”作为差异化壁垒。
2. **最优先解决信任问题。** 对年份、招生计划、选科限制和志愿单位进行结构化规则校验；LLM 仅生成可回溯的解释。
3. **以最小范围做质量验证。** 一个省份 × 一个批次 × 一类志愿单位；数据一致性抽查、规则用例、历史回测和人工盲测先于规模扩展。
4. **保留人类决策权。** 只输出辅助性草表和风险提示，不声称录取保证、不要求用户提供官方填报账号或密码。

## Evidence discipline / 证据标准

本项目的公开资料调查并不构成产品市场契合验证；厂商披露的使用量不能等同于独立活跃或真实付费人数。文稿标注 **事实、用户反馈、厂商口径、分析、待验证**，并在附录给出来源与适用边界。
